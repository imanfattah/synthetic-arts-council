# Governance

## Project status

Synthetic Arts Council is an experimental open-source specification and reference implementation. It is not an arts council, public authority, representative body, or substitute for consultation.

## Maintainer authority

Repository maintainers may accept changes to the project but cannot use repository governance to manufacture cultural or institutional legitimacy. Maintainers must preserve:

- traceability from source to recommendation;
- explicit uncertainty and evidence gaps;
- dissent and minority positions;
- separation between simulation outputs and verified institutional decisions;
- human authority over consequential decisions.

## Protected boundaries

The project must not:

- imply endorsement, partnership, or authority from a referenced institution;
- ingest confidential or unlawfully shared records;
- present committee agents as representatives of artists or communities;
- permit autonomous publication or implementation of institutional decisions;
- suppress dissent merely to produce a clean recommendation.

## Changes to decision rules

Changes that affect evidence admission, committee independence, confidence, deliberation, minority positions, or human review should be documented as governance changes and reviewed more carefully than routine corrections.
