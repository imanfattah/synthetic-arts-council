# Security and responsible disclosure

This repository currently contains configuration, documentation, templates, and a local validator. It does not provide a production service.

Do not open a public issue containing credentials, private records, personal data, confidential institutional material, or exploitable security details. Report sensitive issues privately to the repository owner through GitHub's private vulnerability reporting feature when available.

Evidence-pack contributors must remove secrets and personal data that are not necessary, lawful, and approved for the experiment. A source being accessible to a contributor does not automatically mean it may be republished.

Model-generated content should be treated as untrusted input. Future executable versions must validate structured outputs, constrain file and network access, and keep consequential actions behind explicit human review.
